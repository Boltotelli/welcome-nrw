# NRW Bear Optimizer

## Platform
Web, static browser JavaScript, with existing shared profile service.

## Users and purpose
Kingshot alliance [NRW]United in kingdom 1044 prepares one starter and up to six joiner marches. Quick mode uses heroes and troop stock; advanced mode adds independent base combat statistics, ministers, pets and Valora.

## Constraints
Preserve saved profile structure, numeric PIN access, player search, favorites, leadership consumption of results, four languages and existing community-model calculations. No additional skill-level inputs, export, OCR, external player queries or paid services. Explain unknown skill levels as star-derived assumptions, not confirmed game facts.

## Assets and identity
Reuse the repository's catalog portraits and original Bear/formation media. NRW gold and an understated tactical gaming identity, with compact mobile controls. Portrait URLs remain owned by their existing sources.

## Deployment
Pages composes main's active V3 files through the existing reusable publisher. Vercel currently uses a different Git baseline; release only the scoped Bear commit onto that baseline after Pages verification.
